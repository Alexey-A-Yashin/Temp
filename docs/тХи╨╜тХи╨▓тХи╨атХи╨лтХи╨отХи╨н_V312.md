## КАКОЙ ПРИБОР НА КАКОЙ ВОПРОС ОТВЕЧАЕТ

Это надо держать в голове, иначе числа снова сравнят не с тем.

| вопрос | прибор | где считается |
|---|---|---|
| правдоподобен ли рельеф | геоморфоны, Хортон, перекос | стенд, по полю |
| куполом ли территория | доля высоты в середине минус на краю | стенд, по полю |
| есть ли вода | доля ячеек дренажа с руслом шире 30 м | стенд, по дренажу |
| что видно с точки | доля неба, три плана, слои глубины | стенд, `ViewAudit` |
| сколько пятен в кадре | сведение к трём тонам | **игра**, `[кадр]` |
| сколько областей в шаблоне | проход опознавателя | **игра**, `[sketch]` |
| сколько краски потратит игрок | разложение по шести пигментам | **игра**, снимки + стенд |

**Стенд не умеет цвет.** `Render.EyeView` красит рельеф своей формулой и палитры
поясов не знает. Значит всё, что зависит от цвета — пятна, пигменты, — считается
только по снимкам игры. Заводить палитру на стенде нельзя: это была бы вторая
реализация той же величины.

**Съёмка сведена (2026-08-17).** Обзор 75°, отношение сторон 1.778, дальность до
края территории, цвет неба как в игре. До этого стенд снимал с обзором 62° и
отношением 2.65, и все числа «красивых кадров» из раздела 4г файла решений с
игрой несопоставимы.

## Размен, который надо назвать

Один и тот же переезд взял главную меру и уронил построение:

```
                было (лес)   стало (редколесье)   цель
ходовой пигмент     55.8%           27.0%         <= 33
неба                0-24%           36-46%        15-60
пятен                 5-7             2-4          7-15
крупнейшее          30-33%          61-64%        15-35
```

Полоса велосипеда — это Shrubland и Alpine, то есть выше леса по построению
(раздел 6). Значит вертикалей там нет и не будет, пока их не поставят нарочно.

Это ровно то, о чём говорит Kemp: **передний план надо СОЗДАВАТЬ рядом с точкой
обзора, если его нет.** И то, что записано в разделе 4в: не хватает вертикалей и
плоской земли; три источника из четырёх указывают на одно.

**Вывод для работы:** старт из сети — верно, но опора выбирается по проезжести, а
не по виду. Пока оценка вида не переехала в построитель (план 9.2) и пока
растительность не ставится обрамлением (Kemp), кадр будет пустым.
