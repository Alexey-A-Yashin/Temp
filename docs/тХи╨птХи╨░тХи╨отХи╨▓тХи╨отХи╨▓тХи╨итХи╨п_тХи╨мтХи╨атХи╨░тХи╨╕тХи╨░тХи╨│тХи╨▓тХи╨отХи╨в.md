## 2. КАК ЗАПУСТИТЬ

```
sh подготовить.sh <путь к проекту>      # разворачивает ВСЕ ЧЕТЫРЕ стенда
cd routes
SEP=2000 R=3 KM=20 dotnet run
```

| переменная | что задаёт |
|---|---|
| `KM` | сторона рабочего окна, км. Сетка всегда 60 м — то, по чему игрок едет |
| `R` | радиус маски направлений: 1 — восемь соседей, 3 — 32 направления |
| `SEP` | шаг раздачи опор по территории, метры |

`подготовить.sh` копирует в `routes/` ещё и `gentest/Ringgen.cs` — построение
колец без Godot.

## 3. ЧТО В НЁМ РЕШЕНО

Пять задач, каждая с обоснованием из его пояснения. Это самое ценное: их не
придётся решать заново.

### 3.1. Маска направлений решает всё

На восьми соседях траверс поперёк склона возможен только под 45° к линии
падения, и трасса вырождается.

```
маска           длина трассы по четырём мирам
восемь соседей  0.4 / 1.2 / 27.8 /  7.3 км
радиус 3        24.6 / 21.2 / 24.8 / 7.2 км
```

**Это ровно тот долг, что записан в передаче дел:** уклон ближнего кольца 20–28°,
велосипеду доступно 14% площади. Маска направлений — половина ответа.

### 3.2. Длинный шаг проверяется по всей длине

Иначе путь перепрыгивает промоину, увидев только концы.

### 3.3. Срезка в стоимости

К стоимости добавлено отклонение рельефа от прямой нити между концами шага.
Без неё трасса «летает» над складками. Предел 12 м.

### 3.4. Опоры раздаются по клеткам, а не жадно

Жадный выбор по толщине полосы кучкует опоры, и сеть садится в один угол: размах
40–49% против 62% при раздаче по клеткам `SEP × SEP`.

### 3.5. Перевалы ищутся отдельно

Седловина — точка, вокруг которой более высокие соседи образуют **два и более
отдельных участка** кольца соседей. Обычным поиском их не найти.

ехать, а не только про проходимость.

## 5. ЧЕГО В НЁМ НЕТ

**Оценки вида.** Он ведёт трассу по стоимости рёбер — крутизна, срезка, вода, —
и о том, что с маршрута видно, не знает ничего.

Это и есть работа, записанная в плане: `ViewScore` из `FarBackground` должна
переехать в него, чтобы маршрут шёл **через места с лучшими видами**, а не просто
по проходимым.

## 6. ПРЕДУПРЕЖДЕНИЕ

В пояснении к `подготовить.sh` записан урок, стоивший трёх дней:

> `routes` забыли добавить в скрипт при заведении, и его `src` три дня оставался
> копией кода ДО V219 — с засыпкой впадин внутри водной эрозии. Прототип и проект
> считали РАЗНЫЙ рельеф, и сверка переноса не сходилась.

**Правило:** каждый стенд, заведённый в скрипте, должен там и обновляться. И
запускать `подготовить.sh` после каждой правки в проекте — иначе меришь старый
код.

Скрипт в приложенном архиве исправлен: разворачивает все четыре стенда, и это
проверено — каждый собирается с нуля без ошибок.
