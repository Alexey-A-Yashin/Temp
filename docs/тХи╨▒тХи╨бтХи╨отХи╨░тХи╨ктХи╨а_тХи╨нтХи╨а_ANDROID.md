# СБОРКА НА ANDROID: ПОШАГОВО

Составлено 2026-08-16 для Godot 4.7 + C#.

**Цель этой сборки — узнать, запускается ли игра на телефоне вообще.** Не
качество, не скорость: ответ «да» или «нет».

---

## ЧТО УЖЕ ГОТОВО В ПРОЕКТЕ

Проверил, править не нужно:

- `Godot.NET.Sdk/4.7.0`, для Android заявлен `net9.0` — верно, Android требует
  .NET 7 и выше;
- отрисовщик `renderer/rendering_method="mobile"` — верно для телефона;
- в `config/features` есть `"Mobile"`;
- стартовый экран имеет **кнопки**, нажимаемые пальцем: «Открыть игровой уровень»
  и «Открыть галерею». Клавиатура для проверки не нужна;
- облегчённое построение включается само при `OS.GetName() == "Android"`.

**Добавлено в этой сборке:** `window/handheld/orientation=1` — альбомная
ориентация. Без неё телефон запускает в книжной, и кадр не читается.

---

## ШАГ 1. ШАБЛОНЫ ЭКСПОРТА

В редакторе: **Editor → Manage Export Templates → Download and Install**.

Скачается около 800 МБ. Версия шаблонов должна ТОЧНО совпадать с версией
редактора: если редактор 4.7.1, шаблоны 4.7.1. Иначе экспорт молча не соберётся.

---

## ШАГ 2. OPENJDK 17

Android-экспорт требует именно **JDK 17**, не 21 и не 11.

Проверить: `java -version` в командной строке.

Если нет — поставить Microsoft OpenJDK 17 или Temurin 17.

---

## ШАГ 3. ANDROID SDK

Проще всего — **Android Studio**: он ставит SDK, платформенные инструменты и
инструменты сборки одним махом.

Нужны в SDK Manager:
- Android SDK Platform-Tools
- Android SDK Build-Tools (последняя)
- Android SDK Platform 34 или выше
- NDK — **не нужен**, если не пишете нативные расширения

Путь к SDK по умолчанию:
`C:\Users\<имя>\AppData\Local\Android\Sdk`

---

## ШАГ 4. НАСТРОЙКИ РЕДАКТОРА

**Editor → Editor Settings → Export → Android**:

- **Java SDK Path** — папка JDK 17
- **Android SDK Path** — папка SDK из шага 3

Если пути верны, слева от них появится зелёная галочка. Если красный крест —
дальше идти бессмысленно, проверяйте пути.

---

## ШАГ 5. ОТЛАДОЧНЫЙ КЛЮЧ

Там же, в **Export → Android**, есть кнопка **Create Android Debug Keystore**
(или поле `Debug Keystore`).

Нажать — Godot создаст ключ сам. Для отладочной сборки этого довольно; ключ для
магазина понадобится позже.

---

## ШАГ 6. ПРЕСЕТ ЭКСПОРТА

**Project → Export → Add… → Android**.

В пресете:

| поле | значение |
|---|---|
| Architectures | **только `arm64-v8a`** |
| Export Format | APK |
| Package → Unique Name | `com.example.coloringbook` (или своё) |
| Version → Code / Name | 1 / 1.0 |

Снять `armeabi-v7a`, `x86_64`, `x86` — они не нужны и утяжеляют сборку.

**Про предупреждение о C#.** В пресете будет надпись, что поддержка C# на
мобильных экспериментальная. Это ожидаемо — ровно это мы и проверяем. Не
блокирует экспорт.

---

## ШАГ 7. ЭКСПОРТ

**Export Project…** → выбрать папку → имя `coloringbook.apk`.

Снять галочку **Export With Debug**, если хотите сборку побыстрее; но с ней
проще смотреть журнал, так что для первого раза **оставьте**.

Если экспорт падает с ошибкой — скопируйте её целиком, по ней будет видно, чего
не хватает.

---

## ШАГ 8. УСТАНОВКА НА ТЕЛЕФОН

**Проще всего — прямо из редактора.** На телефоне включить отладку по USB
(Настройки → Для разработчиков → Отладка по USB), подключить кабелем, и в Godot
справа сверху появится значок с названием телефона. Нажать — Godot соберёт и
запустит.

**Или вручную:** скопировать APK на телефон и открыть; разрешить установку из
неизвестных источников.

---

## ЧТО СМОТРЕТЬ ПРИ ЗАПУСКЕ

По порядку важности:

1. **Запускается ли вообще.** Если падает сразу — это и есть главный ответ, и
   тогда решаем про стек.
2. **Сколько секунд до стартового экрана.** Известная беда .NET на Android:
   холодный запуск может занимать до 26 секунд на слабом устройстве из-за
   компиляции на лету. Если так — лечится опережающей компиляцией, это дни
   работы.
3. **Сколько секунд строится уровень** после нажатия кнопки. Ожидание около
   двадцати.
4. **Сколько кадров в секунду.** Отладочная строка сверху их показывает.
5. **Не вылетает ли по памяти.** Бюджет на телефонах 1.5–3 ГБ.

---

## ЖУРНАЛ

Пишется на устройство. Достать проще всего так:

```
adb logcat -s godot
```

`adb` лежит в `platform-tools` из шага 3.

В журнале ищите строку:

```
[устройство] Android, построение ОБЛЕГЧЁННОЕ, ядер N
```

Если её нет — облегчённый режим не включился, и уровень будет строиться минуты.

---

## ЕСЛИ НЕ ЗАПУСТИТСЯ

Это тоже ответ, и он важен сейчас, а не через полгода.

Наше положение при этом лучше среднего: **генерация написана как чистая
библиотека без Godot** — тридцать тысяч строк, которые переносятся куда угодно
без правок. От движка зависит только слой представления, около десяти тысяч
строк.

Порядок вариантов на этот случай:

1. **Опережающая компиляция** вместо среды на лету — если проблема в скорости
   старта. Дни работы.
2. **Слой представления на GDScript**, ядро оставить на C# — появляется и
   веб-экспорт.
3. **Unity** — C# работает и на мобильных, и в вебе; ядро переносится без
   правок.

О веб-экспорте отдельно: **C# в Godot 4 в веб не экспортируется вовсе**, и это
принципиальное ограничение среды .NET в браузере. То есть играбельной рекламы и
быстрого веб-прототипа у нас не будет ни при каком исходе, пока стек такой.
